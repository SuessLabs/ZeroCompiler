## About

The Zero programming language has its inceptions in 2003 and is aimed to be a simple, fast, and efficient programming language created by Damian Suess. At the time of writing, C/C++, Visual Basic, and Java were the key programmang languages for creating a compiled application. Marriaged with the C-like style, the simplicity of VB, and a sprinkle of assembly, the Zero compiler language was concieved.

This repository is a rewrite of the engine based on the original designs.

## Features

Future iterations will be self-hosted instead of written in C# and is designed to be cross-platform.
