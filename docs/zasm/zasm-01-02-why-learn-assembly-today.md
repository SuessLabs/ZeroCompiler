# Why Learn Assembly Today?

Section 1 — Intro · Chapter 1.2

[Previous](zasm-01-01-what-is-zero-assembly.md) · [Contents](index.md) · [Next](zasm-01-03-installing-zero-ide.md)

Assembly makes the work of a program visible: values move through registers,
branches choose the next instruction, and calls enter another routine or the
operating system. These steps help you read debugger output and understand
code generated by higher-level languages.

Begin with a small goal: follow one value from input to output. You do not need
to memorize instruction encodings before writing your first program. Here you
will print text, manipulate numbers, and build a small Windows editor.

Assembly makes responsibilities explicit. A buffer has a capacity; a pointer
has an address; a called function expects arguments in a particular layout.
The compiler cannot infer all of these contracts for you.

Keep three questions beside each example: What value changes? Where is it
stored? Who owns the storage? They become useful when stepping through calls.

> **Exercise:** Identify an operation in a familiar application that needs
> arithmetic, one that needs a branch, and one that asks the OS for a service.
